Academic project achievements in state estimation, localization, and machine learning:

- **State Estimation for AGVs:** Implemented Extended Kalman Filter (EKF) and Particle Filter for an Automated Guided Vehicle (AGV) in MATLAB.
- **Catamaran Localization:** Estimated the position and attitude of an autonomous catamaran using a complementary filter integrating GPS, IMU, and magnetometer data.
- **ECG Classification:** Utilized Deep Learning tools for the classification and analysis of ECG physiological signals.
