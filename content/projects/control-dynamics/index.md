Academic project achievements in advanced control systems and robot dynamics:

- **Reverse Priority Control:** Implemented the Reverse Priority algorithm for a Human-Like trajectory reaching task utilizing a Franka Emika Panda manipulator and a qb-SoftHand1.
- **Adaptive Control:** Combined dynamic and kinematic Adaptive Control methodologies for a 3 DoF robotic manipulator.
- **MAV Observability:** Analyzed observability and implemented Feedback Linearization for Flapping-Wing Micro Air Vehicles (MAVs).
- **Self-Balancing Robot:** Built and controlled a real-time self-balancing robot with Arduino Uno using C, Allegro, and Pthreads.
